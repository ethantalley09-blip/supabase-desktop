Dana Reyes for State Senate

This page stands in for a real campaign's actual website — the point is that everything on this page except the chat bubble in the bottom-right corner is ordinary, unrelated site content. The bubble and the panel it opens are the entire embed footprint.

A real site would drop this at the bottom of its own HTML, right before </body>: 

<script
  src="widget.js"
  data-chat-url="http://localhost:8501"
  data-color="#635bff"
></script>

data-chat-url is the only thing that changes between sites — it's wherever the actual Streamlit app (app.py) ends up deployed. Everything else — position, color, open/close behavior — is handled by widget.js alone; the host page needs zero other code or CSS.
